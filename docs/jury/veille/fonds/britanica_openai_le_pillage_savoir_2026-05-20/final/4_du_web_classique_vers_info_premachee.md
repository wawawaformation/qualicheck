# Du web classique à l'information prémâchée

## Idée centrale

Une transformation majeure de notre rapport à l'information : le web classique orientait l'utilisateur vers des sources identifiables, tandis que l'IA agentique fournit directement une réponse synthétique, souvent détachée du trajet qui a permis de la produire.

On passe ainsi d'une logique de navigation à une logique de substitution.

## 1. Le web classique : une machine à situer

Dans le modèle classique du web, l'utilisateur cherche, clique, compare et vérifie. Les moteurs de recherche et les liens hypertextes ne remplacent pas la source : ils y conduisent.

Le savoir reste donc situé. Il conserve une adresse, un auteur, une date, un contexte de publication, une institution ou un média d'origine. Même lorsque la recherche est imparfaite, le lecteur peut encore remonter vers le document initial.

Ce modèle repose sur une médiation visible :

- des liens ;
- des pages ;
- des auteurs ;
- des chercheurs ;
- des éditeurs ;
- des institutions ;
- des documents consultables.

Le lecteur reste actif. Il doit parcourir un chemin, parfois complexe, mais ce chemin fait partie de la vérification.

## 2. L'IA agentique : une machine à sorties

Avec l'IA agentique, l'interface ne se contente plus d'orienter l'utilisateur vers une source. Elle produit une réponse directement exploitable.

Cette réponse peut être claire, rapide et utile. Mais elle remplace souvent le trajet documentaire : l'utilisateur n'a plus besoin de visiter le site, de lire l'article, de comparer les sources ou d'identifier les auteurs.

L'IA devient alors une machine à sorties : elle transforme une pluralité de contenus en une synthèse unique, fluide et prête à l'emploi.

## 3. Le risque : l'effacement du trajet

Le principal risque n'est pas seulement que l'IA se trompe. Le risque est que les conditions de production du savoir deviennent invisibles.

Dans le web classique, on peut voir le chemin :

- une requête ;
- une liste de résultats ;
- des liens ;
- des pages sources ;
- des auteurs ;
- des dates ;
- des contextes.

Dans le modèle agentique, ce chemin peut disparaître derrière une réponse finale. L'utilisateur reçoit une formulation propre et cohérente, mais il ne voit plus nécessairement les sources, les choix, les limites ou les incertitudes.

## 4. De la source à l'information prémâchée

L'information prémâchée désigne une information déjà digérée par l'interface. Elle est présentée comme immédiatement compréhensible, sans exiger de parcours critique.

Cette simplification a un avantage évident : elle fait gagner du temps et rend l'information plus accessible. Mais elle peut aussi transformer l'utilisateur en simple consommateur de sorties.

Le danger est de confondre :

- une réponse bien formulée avec une information fiable ;
- une synthèse rapide avec une compréhension réelle ;
- une interface fluide avec une source vérifiable ;
- une sortie plausible avec un savoir situé.

## 5. Comparaison des deux modèles

| Caractéristique | Web classique | IA agentique |
| --- | --- | --- |
| Objectif | Orienter vers la source | Fournir une réponse finie |
| Mécanisme | Liens et redirection | Substitution et synthèse |
| Rôle de l'usager | Navigateur critique | Consommateur de sorties |
| Rapport aux sources | Sources visibles et consultables | Sources parfois masquées ou résumées |
| Effort demandé | Parcours, comparaison, vérification | Lecture immédiate d'une réponse |
| Risque principal | Se perdre dans la complexité | Croire une réponse sans voir son origine |

## Conclusion

L'image ne critique pas seulement l'IA comme outil. Elle montre que l'IA agentique modifie la structure même de l'accès au savoir.

Le web classique obligeait l'utilisateur à parcourir un réseau de sources. L'IA agentique tend à remplacer ce parcours par une réponse prémâchée. Ce changement rend l'information plus rapide et plus confortable, mais il peut aussi affaiblir la vérification, l'esprit critique et la visibilité du travail humain qui produit le savoir.

L'enjeu n'est donc pas de refuser l'IA, mais de préserver le lien avec les sources : une bonne réponse doit rester reliée à une origine identifiable, consultable et discutable.
