# Agent docs

Dossier de contexte compact pour les sessions agent.

## Fichiers

- `01_contexte_projet.md`: contexte metier et objectifs
- `02_regles_execution.md`: contraintes d'execution
- `03_references_impl.md`: references a consulter avant codage
- `04_contexte_actif.md`: lecture minimale pour contexte efficace

## Principe

Le detail historique est conserve ailleurs (`CHANGELOG.md`, `docs/superpowers/`, `docs/jury/`).
Ici, on garde uniquement ce qui est necessaire au demarrage rapide d'une session.
